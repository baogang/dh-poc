# BALADY 助理：20 个市民手动测试场景

测试页面：[BALADY 助理](https://road-pothole-pi-poc.onrender.com)，本轮发布源码 `5978237`。请使用现有网站访问认证；页面内“模拟登录”与网站访问认证分别处理。

这些场景检查市民能否用自己的话表达需求，以及助理能否正确查询、追问、说明限制和呈现结果。首句话可直接复制，不需要了解接口、内部编号或执行步骤。

当前网站连接本地 CRM 仿真。查到的记录、上传和提交都不是正式政府业务，不能在官方应用查到，也不会发送真实通知、安排维修或办理退款。姓名、邮箱、电话、街道和门牌示例均为合成测试资料；不得将它们当作官方地址或分类。需要登录时使用页面的模拟登录入口，不在聊天中发送密码或证件号码。 需要提交且只给了完整姓名时，助手应只澄清尚不明确的名、姓角色；在有明确标签的字段填写即可，不能擅自拆分或重复索要已给出的联系方式。

每项从新会话开始；“后续可提供的事实”只在助理需要时补充。第 15、16 项的补充发生在同一会话、提交确认之前。查询场景以当前账号实际返回的记录为准；不存在的记录应如实说明，不能为了满足场景造出记录。

记录测试结果时，将“实际模拟查询/提交成功”“需要补充事实”“当前能力限制”“已取消/拒绝越权”分开。后面三种可能是正确行为，但不能计为市政事项办理成功。

同时检查手机与桌面显示：列表和表格可读，阿拉伯语方向与换行正常，确认卡能看清内容，原始技术回执默认折叠，错误提示说明如何继续。不要仅凭出现“完成”字样判断通过。

为减少叙述编造，本地助理的公众表单描述采用用户实际提供的原话片段，允许大小写和空白排版调整；这会限制自动润色与翻译，需要重述时可在可读确认卡中实际编辑描述，此措施不是官方接口的字段限制。

这些是供人工执行的场景说明，不是新的盲测分数；自动回归和独立语义审查结果另见 `docs/evaluation/`。
